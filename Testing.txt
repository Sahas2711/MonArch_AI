## 1. System Requirements & Architecture Overview

### Prerequisites
- **Operating System**: Windows 10/11, macOS, or Ubuntu 20.04+
- **Python**: Version `3.11`, `3.12`, or `3.13` (64-bit)
- **Disk Space**: ~500 MB (including Python packages and virtualenv)
- **Network**: Internet connection for initial package downloads; core rule evaluation, scoring, and interest calculation run 100% offline.

### What Makes This System Deterministic & Safe?
Unlike generic legal chatbots that can hallucinate contract interpretations, **Vasooli** uses:
1. **Cedar Policy Engine**: Compiled AWS Cedar policies enforcing Section 15 (45-day cap) and Section 16 (3x RBI compound interest) of the MSMED Act 2006.
2. **Deterministic Risk Scorer**: Arithmetic deduction model (0–100) with auditable per-rule point breakdown.
3. **Compound Interest Engine**: Monthly rest interest compounding ($A = P(1 + r/12)^n - P$) at $19.5\%$ p.a. benchmark rate.
4. **Decision Recommendation Ladder**: Progressive 3-tier escalation path based on contact attempts and elapsed days.
5. **Confidence Gate**: Automatic approval for clear cases ($\ge 0.95$) and human review routing for low-confidence or ambiguous phrasing ($< 0.80$).

- `recommended_actions[0].action_type`: `"send_demand_letter"` (Stage 1)

## Step 8: Troubleshooting & Frequently Asked Questions

### 1. `pytest : The term 'pytest' is not recognized`
**Fix**: Always invoke pytest through the virtualenv python:
```powershell
.\.venv\Scripts\python.exe -m pytest tests/ -v
```

### 2. `ModuleNotFoundError: No module named 'api'`
**Fix**: Run tests from the project root directory or pass `PYTHONPATH`:
```powershell
$env:PYTHONPATH="."
.\.venv\Scripts\python.exe -m pytest tests/ -v
```

### 3. `Port 8000 is already in use`
**Fix**: Launch on a different port:
```powershell
.\.venv\Scripts\uvicorn.exe api:app --host 0.0.0.0 --port 8080 --reload
```

### 4. `HTTP 429 Too Many Requests during manual testing`
**Reason**: Organization quota exceeded on the `Free` tier (5 audits/mo).  
**Fix**: Pass a new organization header (e.g. `-H "X-Org-ID: org_test_2"`) or upgrade the org plan in SQLite:
```powershell
.\.venv\Scripts\python.exe -c 'import sqlite3; conn = sqlite3.connect("monarch.db"); conn.execute("UPDATE organizations SET plan_tier = \"enterprise\" WHERE org_id = \"org_default\""); conn.commit()'
```
